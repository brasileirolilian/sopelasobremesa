# Data Model: Post Detail & Sobre Page Polish

**Feature**: `005-fix-post-sobre-details` | **Date**: 2026-05-10

## Entities

### Post (existing, no schema changes)

| Field | Type | Source | Notes |
|-------|------|--------|-------|
| `title` | string | Front matter | Used in post header and related posts cards |
| `date` | datetime | Front matter | Formatted as "DD de MMM de YYYY" |
| `categories` | array | Front matter | `categories[0]` used for related post matching |
| `image` | string (path) | Front matter | Used in related post cards; must be `.webp` |
| `content` | markdown | Post body | Word count used by `reading-time.html` |
| `url` | string | Generated by Jekyll | Used in category links and related post links |
| `excerpt` | string | Auto-generated | Used in related post cards |

### Author Section (new include, no data model change)

Static data hardcoded in `_includes/author-section.html`:

| Field | Value |
|-------|-------|
| Photo | `/assets/img/lilian-brasileiro.webp` |
| Name | Lílian Brasileiro |
| Bio | "Formada em Produção Editorial, adora cinema e livros…" |

### Related Post (computed at build time, no storage)

| Field | Source | Notes |
|-------|--------|-------|
| `title` | Post front matter | Displayed as link |
| `url` | Jekyll generated | Link href |
| `image` | Post front matter | Thumbnail in card |
| `date` | Post front matter | Formatted date |
| `categories[0]` | Post front matter | Used for matching logic |

**Matching logic** (Liquid pseudocode):
```liquid
{% assign current_cat = page.categories[0] %}
{% assign related = site.posts | where_exp: "p", "p.categories contains current_cat and p.url != page.url" | limit: 3 %}
{% if related.size == 0 %}
  {% assign related = site.posts | where_exp: "p", "p.url != page.url" | limit: 3 %}
{% endif %}
```

### Category Link (computed from post front matter)

| Field | Computed As | Example |
|-------|-------------|---------|
| Label | `category` (raw string) | `Receitas` |
| Href | `/categoria/{{ category | slugify }}/` | `/categoria/receitas/` |

## Component Interfaces

### `_includes/author-section.html`

No parameters. Renders full `.author-section` block with photo, name, bio.

Usage: `{% include author-section.html %}`

### `_includes/reading-time.html`

Existing interface (no changes):

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `include.post` | Post object | Yes | Post whose `content` is word-counted |

Usage in post layout: `{% include reading-time.html post=page %}`
